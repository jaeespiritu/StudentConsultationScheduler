STUDENT CONSULTATION SCHEDULER — LOCALHOST + RAILWAY

FOR LOCALHOST (Windows):
1. Extract this ZIP.
2. Double-click START_HERE.bat.
3. Visit http://127.0.0.1:8443 if the browser does not open automatically.
Python 3.9+ must already be installed. No other packages are needed.

FOR RAILWAY (accessible to your professor):
1. Read DEPLOY_RAILWAY.md carefully.
2. Upload the project files to a PRIVATE GitHub repository.
3. Deploy on Railway using the included Dockerfile and railway.json.
4. ATTACH A PERSISTENT VOLUME AT /data BEFORE SAVING BOOKINGS.
5. Generate a Railway domain and test logins/consultations.

The six classroom accounts are automatically seeded into SQLite on first start.
Use the same IDs/emails and passwords you originally provided.
Do not publish the private GitHub source or use real student data in this demo.
